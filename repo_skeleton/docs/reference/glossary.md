# Glossary

Investigation-specific terms, one per entry, with the definition used in this record. Add a term the first time it is used in a decision, claim or handoff.

| Term | Definition | Source |
|---|---|---|
| module | A unit of work with one contract and one handoff, named `mNN_<name>` | D-001 |
| run | One execution in `work/<module>/<run_id>/`, immutable once finished | D-002 |
| claim | One reportable value or interpretation, held in the claims ledger | D-001 |
